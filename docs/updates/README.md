# Updates — per-phase feature summaries

A plain-language, **feature-level** recap of what each development phase delivered —
no code, no deep architecture, just "what can it do now". Each file also carries:

- **Good to know** — what to try, what works and what doesn't yet (for whoever tests a build).
- **Useful Commands** — the shell commands (Windows / WSL / Docker / Chrome / Puppeteer) handy for testing that phase.

This folder is intentionally **not linked** from the rest of the documentation: it is a
companion changelog-in-prose, not part of the canonical wiki tree.

- [phase-00.md](phase-00.md) — Pipeline & infrastructure
- [phase-01.md](phase-01.md) — Foundations (auth, shell, profile)
